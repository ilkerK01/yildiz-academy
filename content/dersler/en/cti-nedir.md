Cyber threat intelligence (CTI) is the work of producing **actionable**
information about the threats an organization faces. The key word is
actionable: information nobody acts on is not intelligence, it is just data.

## Three levels

**Tactical.** File hashes, IP addresses, domain names. Short-lived; they lose
their value the moment an attacker changes infrastructure. This is the layer
that feeds automated systems.

**Operational.** How a campaign runs: which tool, which delivery method, which
timing. This is the layer a defensive team uses when writing detection rules.

**Strategic.** Who, why, and for how long. The questions an executive asks when
allocating a budget live here.

## Data, information, intelligence

An IP address is data. "This IP was used as a command server in three
different ransomware campaigns in the last 30 days" is information. "The group
using this infrastructure targets our sector and prefers VPN vulnerabilities as
its way in, so we should prioritize our VPN patches" is intelligence.

The difference is analysis and context. Buying a feed is not buying
intelligence.

## Why most CTI programs don't work

Because they start without defining the consumer. If there is no answer to
"Who am I producing this for, and what decision should it help them make?",
what gets produced is not a report but noise.
